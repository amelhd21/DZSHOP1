Étape 1 — Créer la base sur MongoDB Atlas

  1. Va sur mongodb.com/atlas → Try Free → crée un compte.
  2. Crée un projet, puis un cluster → offre M0 (FREE) → Create.
  3. Database Access → Add New Database User → note bien le nom et le mot de passe.
  4. Network Access → Add IP Address → Allow access from anywhere (0.0.0.0/0).
  5. Cluster → Connect → Drivers → copie le lien mongodb+srv://...
2 choses à corriger dans le lien copié : remplace <password> par ton vrai mot de passe, et ajoute /dzshop juste avant le ?.

Étape 2 — Créer le backend

1À la racine de ton projet (pas dans src/) :

mkdir backend
cd backend
npm init -y
npm install express mongoose cors dotenv
npm install nodemon --save-dev

Dans backend/package.json, ajoute "type": "module" et un script dev :

{
  "type": "module",
  "scripts": {
    "dev": "nodemon server.js",
    "seed": "node seed.js"
  }
}

2Crée backend/server.js :

import dns from 'node:dns';
dns.setServers(['8.8.8.8', '8.8.4.4']);   // fix DNS pour Atlas

import express from 'express';
import cors from 'cors';
import mongoose from 'mongoose';
import dotenv from 'dotenv';
dotenv.config();

import produitRoutes from './routes/produits.js';

mongoose.connect(process.env.MONGO_URI)
  .then(function () { console.log('MongoDB connecté'); })
  .catch(function (err) { console.log('Erreur MongoDB :', err.message); });

const app = express();
app.use(cors());
app.use(express.json());

app.use('/api/products', produitRoutes);

app.listen(5000, function () {
  console.log('Serveur sur http://localhost:5000');
});
  • cors() → sans ça, ton frontend (sur un port différent) serait bloqué par le navigateur quand il essaiera d'appeler ton backend. C'est une règle de sécurité normale des navigateurs.
  • express.json() → permet à Express de comprendre le JSON envoyé dans le corps d'une requête.

3Ouvre src/produit.jsx et regarde la forme exacte de tes objets produits. Crée backend/models/Produit.js en respectant EXACTEMENT ces mêmes clés :

import mongoose from 'mongoose';

const schema = new mongoose.Schema({
  nom:         { type: String, required: true },
  prix:        { type: Number, required: true, min: 0 },
  categorie:   { type: String, default: 'Divers' },
  images:      [String],
  description: String
}, {
  timestamps: true
});

export default mongoose.model('Produit', schema);
Adapte les noms de champs à ta vraie structure : j'ai mis des noms probables (nom, prix, categorie, images) — vérifie dans src/produit.jsx les vrais noms de propriétés, et corrige le schema pour qu'il corresponde EXACTEMENT. Un schema qui ne correspond pas à tes vraies données provoquera des champs vides une fois migré.

mongoose.connect(process.env.MONGO_URI)

5Crée backend/routes/produits.js :

import express from 'express';
import Produit from '../models/Produit.js';

const router = express.Router();

router.get('/', async function (req, res) {
  try {
    const produits = await Produit.find();
    res.json(produits);
  } catch (err) {
    res.status(500).json({ message: err.message });
  }
});

router.get('/:id', async function (req, res) {
  try {
    const produit = await Produit.findById(req.params.id);
    if (!produit) {
      res.status(404).json({ message: 'Produit non trouvé' });
      return;
    }
    res.json(produit);
  } catch (err) {
    res.status(500).json({ message: err.message });
  }
});

export default router;
